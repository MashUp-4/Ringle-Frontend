# Ringle Frontend

Mashup 4팀의 React·TypeScript 프론트엔드입니다. 홈, 튜터 추천, 필터가 있는 전체 튜터 화면을 구현하고 있으며 현재는 로컬 데모 데이터를 사용합니다. Figma와의 정합화는 진행 중입니다.

## 실행

Node.js와 npm을 사용합니다. 팀의 정확한 버전 고정은 합의가 필요합니다.

```sh
npm ci
npm run dev
npm run build
npm run lint
npm run format:check
```

패키지 설치에는 커밋된 `package-lock.json`을 사용하며, 의존성 변경 시 `package.json`과 함께 갱신합니다. npm은 기존 저장소의 패키지 매니저를 유지한 선택입니다.

## 화면과 라우팅

- `/`: 홈의 예약 수업 1개 데모 상태
- `/?lessons=0`: 예약 수업과 수업권이 없는 홈 추천 화면
- `/?lessons=0&passes=available`: 예약 수업이 없고 수업권이 있는 홈 추천 화면
- `/?lessons=2`, `/?lessons=3`: 예약 수업 2개·3개 데모 상태
- `/tutors`: 추천 튜터
- `/tutors?tab=전체`: 기존 화면의 전체 튜터 탭
- `/tutors/all`: 필터가 있는 전체 튜터 화면
- `/tutors/all?saved=1`: 찜한 튜터만 표시
- `/tutors/favorites`: `/tutors/all`로 이동하는 기존 경로. 쿼리 문자열을 유지합니다.
- `/tutors/:tutorId`: 튜터 상세 팝업. 현재 데모의 ID는 튜터 이름이며 실제 API 연동 시 서버 ID로 교체해야 합니다.
- 등록되지 않은 경로: 404 안내

튜터 이름·전공·학교로 검색할 수 있습니다. 검색어는 최대 100자입니다. 추천 팝업에서는 관심 분야 선택 전 제출 버튼을 비활성화합니다. 찜하기는 하단 배너를 표시하며 바로가기로 저장 목록을 확인할 수 있습니다.

## 코드 구조

```text
src/
  components/ui/          공통 Icon, Modal
  components/layout/      AppShell, AppNavigation, TutorPageHeader, FloatingActions
  pages/TutorPage.tsx     기존 튜터 화면
  pages/AllTutorsPage.tsx  필터가 있는 튜터 화면
  pages/HomePage.tsx       홈 화면
  pages/HomePage.css       홈 화면 스타일
  features/home/
    components/           HomeTutorCard, ScheduledLessons, ProfileEditor
    data/                 홈 프로필·추천 정보·예약 수업 데모 데이터
    types/                홈 데이터 타입
  features/tutors/
    api/tutors.ts         튜터 데이터 제공 경계
    components/           TutorCard, TutorFilterPanel
    data/                 데모 데이터
    hooks/                목록 조회, 브라우저 북마크 상태
    types/                명시적인 Tutor 타입
  App.tsx                 Route 구성
  App.css                 Tailwind @apply와 화면별 스타일
  index.css               Tailwind 테마 토큰과 전역 스타일
```

컴포넌트·페이지 파일은 PascalCase, 훅은 `use` 접두사, 데이터·타입 파일은 camelCase를 사용합니다. 화면에 종속된 코드는 `features/home`과 `features/tutors`, 재사용 가능한 UI는 `components/ui`에 둡니다.

## 홈 화면

첨부한 ‘수업권 없음’·‘수업권 있음’ 디자인을 한 페이지에서 조건부로 표시합니다. 학습 목표별 추천 카드, 찜하기와 저장 목록 연결, 커리큘럼 선택, 프로필 입력 검증, 배너 및 챌린지 안내를 제공합니다. 홈과 튜터 페이지는 공통 내비게이션을 사용합니다.

예약 수업이 있으면 `ScheduledLessons`, 없으면 홈 추천영역을 표시합니다. 기본 주소 `/`에는 예약 수업 1개가 있으므로 홈 추천카드의 변경사항은 `/?lessons=0`에서 확인합니다.

홈 추천카드는 Figma의 286×522 크기, 252×252 사진, 16px 카드 간격을 적용했습니다. 추천 문구·태그·가장 빠른 수업과 홈 전용 별점을 `homeTutorRecommendations`에서 제공합니다. Figma 예시대로 Anshi는 `selected`의 그림자, Alexander는 `disabled`의 투명도 70%를 표시하며, 이 상태 이름으로 클릭을 막거나 상태 전환 규칙을 추가하지 않았습니다. 커리어/인터뷰 추천은 현재 2개이므로 목록 안에 모두 들어가 다음 버튼을 눌러도 이동하지 않습니다. 가로 목록이 넘치면 카드 너비와 간격만큼 이동하며 반복 이동은 구현하지 않았습니다.

홈의 초기 학습 목표와 ‘가입 시 선택’ 표시는 `HomeProfile.signupGoal`을 사용합니다. 탭 클릭으로 선택한 학습 목표와 가입 목표는 별도 상태이며, 프로필 이름·시간대 수정 시 가입 목표를 유지합니다. 현재 가입 목표는 데모 값이고 실제 API는 연결되지 않았습니다.

튜터 수락률·분야 태그를 포함한 튜터 정보는 `src/features/tutors/data/demoTutors.ts`의 목데이터입니다. API 연동 시 `getTutors`를 실제 요청으로 교체하고 목데이터 파일과 import를 제거합니다. 수업권 잔액, 쿠폰과 챌린지 수치도 데모입니다. 프로필 수정은 현재 페이지 상태에만 반영됩니다. 수업권 구매는 안내 팝업을 열고, ‘바로 예약하기’는 튜터 선택 화면으로 이동합니다. 실제 결제·예약·챌린지 신청·프로필 API는 연결되지 않았으며 완료 상태를 생성하지 않습니다.

## 상태와 데이터 처리

검색어·팝업·알림은 페이지 로컬 상태이고, 탭·상세 튜터는 React Router의 URL 상태입니다. 목록 데이터는 `useTutors`에서 로딩·에러·재시도 상태를 관리합니다. 진행 중인 조회 Promise를 공유해 같은 시점의 중복 호출을 줄이고, 언마운트된 화면에는 결과를 반영하지 않습니다. 현재 데이터 제공 함수는 로컬 데모를 반환하며 네트워크 요청은 발생하지 않습니다.

필터 화면은 기존 데모 튜터 5명과 브라우저에 저장된 찜 상태를 사용합니다. 찜한 튜터 필터는 URL의 `saved=1`로 표시합니다. 수업한 튜터·링글 추천 튜터·50% 포인트백·요일·시간대 필터는 필요한 데이터와 API가 없어 현재 비활성화되어 있습니다.

찜하기는 로그인 계정과 연결되지 않은 브라우저 로컬 기능입니다. 저장된 값은 문자열 배열인지 확인하고, 저장 실패 시 현재 화면의 상태를 유지하면서 사용자에게 알립니다. 서버 북마크로 전환하려면 인증 및 API 계약이 필요합니다. 지금은 전역 공유 상태가 없어 Zustand나 서버 캐시 라이브러리를 추가하지 않았습니다.

## 디자인과 접근성

홈·튜터 추천·전체 튜터 화면은 `AppShell`에서 내비게이션과 예약·문의 버튼을 공유합니다. 홈과 튜터 화면의 이벤트 문구는 경로에 따라 구분하고, 수업 메뉴·튜터 탭·검색창은 공통 헤더를 사용합니다. 공통 치수는 `components/layout/AppShell.css`에서 관리합니다. 피그마의 1920×1080 표시 영역 기준으로 사이드바는 100px, 헤더는 82px, 튜터 콘텐츠 폭은 최대 1340px입니다. 사이드바 메뉴 높이는 튜터 화면 886px, 홈 화면 878px입니다.

모든 화면은 `AppShell`을 공유하며 901px 이상 창에서는 기존 PC 표시 크기를 유지하기 위해 `zoom: 0.8`을 적용합니다. 이 배율은 Figma의 반응형 요구사항이 아닌 구현상의 표시 방식입니다. 기존 `TutorFrame`의 배율 처리는 사용하지 않습니다. Label 18의 CSS 값은 글자 크기 18px·행간 18px·굵기 600이며, PC 전체 축소 후에는 14.4px 크기로 표시됩니다. ‘예습하기’는 Label 18과 상하 20px·좌우 32px 패딩, ‘프로필 설정’은 Label 16 M과 상하 12px·좌우 8px 패딩을 사용하며 두 버튼도 동일한 전체 배율을 적용받습니다.

최종 피그마의 Primitive·Semantic 변수와 텍스트 스타일을 `src/index.css`에서 관리합니다. 색상은 `--color-primary-*`, `--color-ringle-gray-*` 및 용도별 별칭을 사용합니다. 간격은 `--spacing-unit-*`, 모서리는 `--radius-*`, 타이포그래피는 `text-heading-40`, `text-heading-24`, `text-label-20-bold` 등의 Tailwind 유틸리티로 적용합니다. 간격 토큰을 별도 이름으로 정의해 기존 Tailwind `p-4` 등의 값은 유지합니다.

Figma에서 Label 18로 지정한 홈 구매 혜택·추천 더보기·가이드·바로가기·챌린지·프로필 정보·예정된 수업 설명과 일정 변경, 튜터 수 및 찜 추가 알림에는 `text-label-18`을 적용합니다. 해당 문구의 글자 크기를 12~14px로 줄이던 기존 CSS 덮어쓰기는 제거했습니다.

홈 제목은 Heading 24, 학습 목표 탭·추천 설명은 Label 16 Sb, 가입 시 선택·예정된 수업 태그는 Label 14 B, 쿠폰 안내·찜 목록 바로가기는 Label 16 M을 사용합니다. 챌린지 본문은 Figma의 별도 지정값인 20px·굵기 600·행간 32px을 적용합니다. 첫 구매 혜택 문구의 텍스트 영역은 249×24이며 세로 중앙에 배치합니다. 전체 튜터 목록의 카드 글자는 Figma에서 252px 카드를 240px로 축소한 인스턴스의 치수에 맞췄습니다. 이 카드 글자 비율과 PC 전체 80% 표시 배율은 별개입니다.

Pretendard Variable 1.3.9는 `public/fonts`에서 제공하고 첫 화면에서 미리 로드합니다. 외부 폰트 CDN에 의존하지 않습니다. 폰트 출처는 [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard)이며, 배포 라이선스는 `public/fonts/OFL.txt`에 포함되어 있습니다.

Tailwind CSS 4의 테마 토큰과 `@apply`로 공통 레이아웃·색상·타이포그래피를 적용합니다. 첨부 디자인의 크기와 hover 전환 등은 화면 CSS에서 관리합니다. 튜터 추천 첫 섹션은 252px 카드와 20px 간격, 필터 화면은 4열을 기준으로 표시합니다. 추천 첫 섹션의 다음 버튼은 카드 한 장과 간격만큼 이동합니다. 카드 소개는 넘치면 스크롤할 수 있고, 검색창과 버튼은 키보드 포커스를 표시합니다.

공통 Modal은 네이티브 `dialog`로 배경을 비활성화합니다. Escape·닫기 버튼·배경 클릭으로 닫으며, 닫을 때 이전 포커스를 복원합니다.

## Git 협업

기능 브랜치는 `dev`에서 만들고, 작업 브랜치에서 `dev`로 PR을 보냅니다. 팀원 리뷰 후 `dev`에서 통합 검증하고, 이후 `dev`에서 `main`으로 PR을 보냅니다. 커밋은 `feat:`, `fix:`, `refactor:`, `docs:`, `chore:` 접두사를 사용하며 커밋 훅에서 린트와 포맷을 확인합니다.

## 과제 완료를 위해 남은 사항

홈 추천영역의 패딩·탭 간격·예약 버튼 여백, 예정된 수업의 사진·설명·태그·다음 버튼 배치, 구매 혜택·커리큘럼·가이드·OT·바로가기·챌린지·프로필의 공통 배치를 Figma에서 확인한 수치로 수정했습니다. 예약 수업 2개·3개는 별도의 Figma 화면이 없어 동일한 예약 카드 디자인과 기존 이동 동작을 사용하는 데모입니다.

체험 수업 예약 버튼의 hover 배경은 Figma의 `#3d1885`입니다. 튜터 hover는 원본의 29% 검정 오버레이와 태그·수락률·레이어 순서를 반영했습니다. `TutorGlass`는 첨부한 Glass 설정(빛 −45°·80%, 굴절 80, 깊이 20, 분산 50, 흐릿함 4, Splay 0)을 사용해 SVG로 유리 효과를 근사합니다. 사진과 북마크에 효과를 적용하고 수락률·태그는 효과 위에 표시합니다. 원본 사진과 북마크 자산을 그대로 사용하며 카드 크기가 바뀌면 표면 맵을 다시 계산합니다.

이 구현은 Figma의 렌더링 알고리즘과 동일하지 않습니다. 둥근 사각형 표면에서 굴절을 계산하고 RGB 채널별 변위를 분산으로 표현하며 가장자리 조명을 합성합니다. 굴절은 카드 폭에 대한 상대 깊이로 계산하고 가장자리 양끝에서 변위가 0이 되는 표면 모델을 사용해 픽셀이 반복되거나 늘어지는 잔상을 줄입니다. 분산은 굴절의 ±50%가 아니라 깊이와 독립된 서브픽셀 샘플링 차이로 모델링해 가장자리에 넓은 RGB 띠가 생기지 않도록 합니다. 흐릿함 4는 이 모델에서 Gaussian 반경을 두 표준편차로 정의해 SVG 표준편차 2로 계산합니다. 이는 구현상 가정이며 Figma의 공식 CSS/SVG 환산식이 아닙니다. Chromium에서 원본과 시각 비교하고 hover·키보드 포커스·북마크·상세 보기 동작을 검증했지만, 픽셀 단위 완전 일치나 다른 브라우저의 동일한 결과까지 검증한 상태는 아닙니다.

튜터 필터 패널은 Figma의 접힌·펼친 컴포넌트와 동일하게 `border/default`(`#e8e7ed`) 1px 테두리와 16px 모서리를 사용합니다. 필터 전용 CSS가 공통 테두리를 제거하던 덮어쓰기를 수정했습니다.

남은 화면 확인 사항은 다음과 같습니다.

- 실제 관심 분야 데이터를 받은 뒤 추천 설명에 ‘경영’ 등 관심 분야 표시
- 홈 추천 더미를 받은 뒤 일부 보이는 세 번째 카드와 다음 버튼 이동 확인
- 튜터 hover의 SVG 근사 결과에 대한 디자인 검토 및 대상 브라우저별 확인

튜터 추천의 ‘후기로 검증된’·‘숨겨진 실력파’ 등 후속 섹션은 이번 작업 범위에서 제외합니다.

현재 버전은 UI 데모입니다. 아래 항목은 완료되지 않았으며 백엔드·팀 합의 후 구현해야 합니다.

- 역기획 요구사항과 담당 화면 범위 확인
- 실제 튜터 목록·상세·추천·찜하기 API 연동 및 요청·응답 타입 확정
- 인증·권한에 따른 UI, 인증 오류와 중복 변경 요청 처리
- 합의된 API Base URL의 개발·배포 환경변수 설정
- 실제 서버에서 로딩·빈 응답·실패·입력 검증 시나리오 확인
- 예약·고객 지원 등 담당 범위 밖 버튼의 실제 목적지 연결
- 팀 역할·일정·API 선택·병합 정책 등 실제 협업 내용 기록
- 리뷰 반영 후 기본 브랜치 병합, 원격 저장소 제출
- 과제 제출 담당자와 발표 담당자를 서로 다르게 지정

API 주소나 인증 규약은 임의로 만들지 않았습니다. 클라이언트 환경변수는 공개되므로 비밀키를 넣지 않습니다.

### 예약 수업 홈 목데이터

기본 홈(`/`)은 예약 수업 1개를 표시합니다. `/?lessons=2`, `/?lessons=3`에서 여러 수업 캐러셀을 확인하고, `/?lessons=0`에서 기존 추천 화면을 확인합니다. 수업권 보유 추천 화면은 `/?lessons=0&passes=available`입니다.

예약 데이터는 `src/features/home/data/demoLessons.ts`에 있습니다. API 연동 시 해당 파일과 import, URL 기반 데모 분기를 제거하고 실제 예약 목록으로 교체합니다. 여러 수업은 카드 오른쪽의 다음 버튼, 좌우 방향키 및 모바일 가로 스와이프로 이동합니다. 수업이 1개인 상태도 Figma처럼 다음 버튼을 표시하며, 목록 끝에서 반복 이동하지 않습니다. 일정 변경·예습은 아직 안내 팝업이며 실제 예약 변경이나 교재 조회를 수행하지 않습니다.
